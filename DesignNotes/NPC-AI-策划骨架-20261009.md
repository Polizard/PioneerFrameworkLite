# NPC AI 策划骨架（2026-10-09）

> 定位：**策划稿**（不写码）。四份参考＝论文《空间轨道博弈》/ BDArmory / CDE（含全量反编译存档）/ RimWorld 原生机制。
> 原则：**能抄就抄，有限创新**。创新只留两条（都用既有件，不加新机制）。
> 目标：**智能水平略高于 CDE**——定义见 §7（三句可判定的话）。

## 0. 先划三条红线（与既有纪律相容）

1. **不新建"决策层巨型 GameComponent"**（沿设计稿 [D11]）：决策天然分布——每舰一份战术脑、每编队一份战略脑；全局只加"节拍调度"。
2. **NPC 选目标只读认知层**（沿 [V3] 红线 ②）：`SensorManager` 的接触视图（含影子/σ/失联）是唯一输入；"选中之后读该目标的真值元数据"这一既有例外照旧允许（选它 vs 怎么打它）。
3. **不做学习型 AI**（用户已裁定"要大脑不要环境"）：不引入 RL、不引入外部仿真环境；大脑＝规则 + 打分 + 小规模计划。

## 2. 分层架构（4 层 + 1 数据面）

```
[数据面] NpcDoctrine（XML/Def）：人格参数 × 十套起步
                │ 每拍现读（无状态薄壳）
[L3 组织层] 阵营层：Doctrine 分配 · Incident 生成舰队 · 任务下达（StateGraph 语义）
                │ 任务（Mission）
[L2 战略层] FleetBrain（每编队一份）：维护 → 门控 → 主决策（威胁→选目标→计划→执行/降级）
                │ 命令（Command）
[L1 战术层] ShipBrain（每舰一份）：状态机 + 优先级 + 节流/迟滞 + 索敌 + 对抗
                │ 命令写入（唯一写入口）
[L0 执行层] 舰上控制组件：期望推力/朝向 → 推进器分配 → 开火（既有动作词汇表 + 操舵台/控制台）
                ▲
[感知层]    SensorManager 接触视图（已有 [V3]）——L1/L2 的唯一输入
```

- **节拍**：挂在既有物理步序列"**物理 → 能力面 → 认知 → 决策**"的决策槽（`SpaceGameComp.cs:1129-1145`，注释里早就留了门）。不新开计时器：战略脑与战术脑各带**重决策节流**（照 BDA：常规 2–3 s、紧急 0.5 s）。
- **状态归属**：船意图存船（`SpaceEntityGroup` 上的字段，沿既有 [O5] 准入判据）；编队任务存编队；**大脑对象本身不持状态**（抄 CDE 薄壳——可回放、可调参、存档不腐）。

## 3. 命令语言（AI 与玩家共用一套，抄 CDE 的"小而共用的口"）

裁剪 CDE 的 7 条命令 + 接我们的动作词汇表：

| # | 命令 | 参数 | 语义 | AI | 玩家 |
|---|---|---|---|---|---|
| 1 | `机动` | 目标位点/方向 | 给定期望推力方向（推力、朝向各一份载荷） | ✔ | ✔ |
| 2 | `转向` | 期望朝向（四元数） | 一次性，到位自动清令 | ✔ | ✔ |
| 3 | `滚转` | 绕纵轴角 | 对抗受弹截面/散热朝向 | ✔ | ✔ |
| 4 | `交战` | 目标（接触 ID）+ 方式 | 攻击航线：趋近/保持射程 + 开火授权（沿用"寻的"语义，推力走我们的制导核） | ✔ | ✔ |
| 5 | `散开` | — | 远离友军质心、沿敌我质心轴的正交方向 | ✔ | ✔ |
| 6 | `指向` | 目标 | 主武器指向目标（我们的船是任意构型，等价于 CDE 的"摆侧舷"） | ✘(先留) | ✔ |
| 7 | `驻留` | 位点/天体 | **我们特有**：悬浮/定点保持（既有 `HoverCore`/解析搬运） | ✔ | ✔ |
| 8 | `电磁` | 开关集 | 开机/静默/干扰/诱饵（既有 `ActivePingEnabled`/`JammingEnabled`/`InjectDecoy`） | ✔ | ✔ |
| 9 | `发射` | 齐射数/弹种 | 导弹/无人机发射（既有 `AVM.IssueCommand`） | ✔ | ✔ |

要点（抄 CDE 的关键取舍）：**AI 只用少数几条**（1/2/4/5/7/8/9）；姿态精修留给执行层与武器射界；**玩家可对任何 NPC 舰下同样的命令**（接管/指挥体验，零额外 AI 复杂度）。

## 4. L2 战略层（FleetBrain）——主要抄 CDE

**决策单位＝编队**（既有 `SpaceEntityGroup` + 星座/编组关系）。每拍三遍 pass（照 CDE 四遍合并）：

1. **维护遍**：拆分"没油的分队"（抄 `SplitOutShipsWithoutDeltaV`）；全队无战力或油尽 → 解散/撤退（抄 Disband）。
2. **门控遍**：非战斗时收武器、雷达/干扰开关归位（抄 `DisableWeaponsOutsideOfCombat`）。
3. **主决策遍**：
   - 威胁评估 → **选目标**：`分数 = 吨位权重×(吨位/最大) + 距离权重×(1 − 距离/上限)`（抄 CDE 两旋钮），目标须"同天体 + 类型开关匹配"；再加 BDA 的**显式分配防集火**（已被指定/已被围攻的目标降权）。
   - **计划**：生成/更新航程表——不足则降级（见下）。
   - **执行**：把第一个节点的 burn 交 `StartBurn`（原子脉冲口），交会/拦截段走既有引导注册。

**计划对象 `MissionPlan`（抄 CDE `Itinerary`）**：
- 节点 = `{ 时刻, 参考系（天体/编队）, 类型, Δv 账, 期限 }`；节点类型（裁剪自 CDE 的 0/2/3/4 + 论文的任务表）：
  `机动` · `交会友军` · `拦截敌舰` · `监视/巡逻` · `驻留` · `撤离`。
- 重排 = 截断其后节点 → 循环加节点直到可行（抄 `RegenerateTrajectoryAfter`）；**战后自动重排**（抄 `OnFleetChanged`）。

**约束机制（抄 CDE 三件套，这是"像 CDE 一样守纪律"的核心）**：
- **Δv 预算三约束取最小**：`min(剩余 − (1−瞬时预算%)×原始, 总预算%×剩余, 剩余 − 事后重新圆化/返程余量)`，下限 0。
- **免费优先**：能滑行抵达（我们既有交会/转移解算判定）就不点火。
- **期限**：节点时刻超过任务死线 → 报"来不及"并降级（换目标/撤退），不硬冲。

## 5. L1 战术层（ShipBrain）——主要抄 BDArmory + CDE 的索敌

**状态机（8 态，含节流与迟滞）**：

| 状态 | 进入 | 退出 | 备注 |
|---|---|---|---|
| 待命 Standby | 默认 | 有指令/有威胁 | — |
| 巡逻 Patrol | 任务节点 | 发现目标 | 走航程表 |
| 趋近 Approach | 有目标但未进射程 | 进射程/目标失联 | 用 CPA 预测（抄 BDA） |
| 交战 Engage | 进射程且已授权 | 目标丢失/弹药尽/受损 | 每武器索敌 + 分火 |
| 规避 Evade | **来袭撞击时间 ≤ 阈值**（CPA 预测，抄 BDA 的"能赢的最省机动"筛选） | 威胁解除 + 最短规避时长 | 状态单调保守，不抖动 |
| 撤离 Withdraw | 损伤/弹药/油量越线 或 收到撤退令 | 脱离 + 任务节点 | 撤退也是"有计划"的（走航程表） |
| 受损 Disabled | 船体/武器毁损超线 | 修复(未来)/被丢弃 | 只保命、发求救（广播=可探测） |
| 驻留 Hold | 驻留命令 | 新命令 | 走既有悬浮/解析保持 |

- 优先级固定（抄 CDE 的 if 链精神）：**避碰 > 规避 > 交战 > 趋近 > 巡逻/待命**。
- 重决策节流：常规 2–3 s、紧急 0.5 s、指令变化即刷（抄 BDA）。
- **威胁判据**：主判据抄 CDE"**对面还能不能打**"（有 Δv + 有可用武器），但我们**用接触三态加权**——影子接触算"威胁但降权"、失联不算（这就是"略高于 CDE"的第一处）。
- **索敌管线（抄 CDE）**：每阵营目标板（BDA 的 TargetManager 范式）→ 候选 → 排除（射界/射程/掩体/友军，友军仅"与我相撞航线"例外）→ **每武器一份目标表** → **分火轮转 `(武器索引 + 分布索引) % 目标数`**。
- **开火前查认知**：沿用 [V3] S3b 的漏斗，把 `PlayerCanSee` 换成"本方看得见"（同一判据，两个阵营对称）。
- **对抗（接我们的电磁动作）**：干扰/静默/诱饵按条令阈值释放；抄 CDE 热焰的三条判据（在飞数量 < 需要数、有威胁、有效果）映射到我们的诱饵/干扰。

## 6. L3 组织层与威胁生成——主要抄 RimWorld 原生

- **条令即数据**：`NpcDoctrine` Def（XML），十套起步（照抄 CDE 的人格名单与参数族，改成我们的量纲）：

| 条令块 | 参数（抄自 CDE，改我们的量纲） |
|---|---|
| 交战条令 | 交战距离系数、射程豁免（`NeverIgnoreRange`/超弹药阈值/仅对开火者）、**目标优先级序表**（武器/引擎/罐/散热…换成我们的部件类别）、规避阈值、撤离阈值、最短规避时长 |
| 拦截条令 | **Δv 预算%**（瞬时/总）、`DistanceMaximum`、`TonnageWeightFactor`/`DistanceWeightFactor`、目标类型开关（打不打主力舰/导弹/无人机→我们的舰种） |
| 发射条令 | 在飞波数、每波发数、预留数、错峰距离、是否只在有利几何发射 |
| 对抗条令 | 诱饵在飞数量、是否只对无人目标、开关阈值 |
| 全局旗 | 别赖在引力球里、非战斗关武器、是否可被外交约束 |

- **人格＝叙事**（抄 CDE 的包装）：每个敌对指挥官一份条令，简报里告诉玩家"对面风格偏谨慎"，玩家的对策从'看参数'变成'读人'。
- **威胁生成＝事件**（RimWorld 原生）：`IncidentDef`/`IncidentWorker` 生成 NPC 舰队（本体叙事者驱动，天然与本体事件系统、难度曲线、派系关系兼容）；生成即派任务（走 L3 的任务下达）。
- **群体任务语义**：抄 `LordJob` 的 **StateGraph**（目标态 + 触发器），但**不强行塞进 Lord/Job 体系**（空间实体在 Map 之外，已核实进不去）。①轨道层用我们自己的小型状态图 runner；②只有"要有血肉"的旗舰才做 pocket map + 真船员 + 原生 Lord/Duty（可选、后期）。

## 7. 验收判据——"略高于 CDE"的定义（三句话）

1. **同样能打，但只靠接触**：在"AI 只能读认知层"的前提下完成拦截/交战/撤离（CDE 读真值）。⇒ 被干扰/诱饵欺骗时行为**正确退化**（追影子、追丢、恢复），这是 CDE 没有的维度。
2. **同样守纪律**：Δv 花费 ≤ 预算、超期＝0（降级被观测到）、"打不起就不打"。⇒ 用跑批器记录 CDE 同款指标：**耗时 / Δv / 存活率 / 无损率 / 敌方剩余**，每个 AI 场景一份记录。
3. **能被指挥**：玩家可用同一套命令接管任何 NPC 舰（CDE 的 AI 命令玩家也可下，这条我们做到对称）。

## 8. 分期（第一刀必须小）

| 阶段 | 内容 | 判据 |
|---|---|---|
| **0 · 接口**（几乎零新增机制） | 命令对象 + 舰上命令容器（唯一写入口）；决策挂点接进物理步序列；一个"手喂命令"调试件 | 手写命令能让船动、停、开火、开关电磁 |
| **1 · 单舰战术脑** | 8 态状态机 + 节流/迟滞 + 威胁判据 + 每武器索敌 + 分火 + 规避 | 跑批器：一对一（NPC vs 目标）自主索敌→交战→规避→撤离全链 |
| **2 · 舰队战略脑** | 编队为决策单位 + 三遍 pass + 选目标两旋钮 + 预算三约束 + 免费优先 + 期限 + 简化航程表 | 跑批器：NPC 舰队拦截机动目标；缺油/超期**降级**被观测到 |
| **3 · 组织与威胁生成** | `NpcDoctrine` Def 十套 + Incident 生成舰队 + 任务下达 + 叙事包装 | 叙事者按事件生成 NPC 舰队并完成任务链（含撤退） |
| **4 · 评测与难度** | 指标记录 + 难度＝参数集 + 与玩家交战的平衡档 | 每场景一份 CDE 式记录；三档难度只差参数 |

**推荐起点**：阶段 0 + 1（做完就能在游戏里看到"一艘会自己打架的船"）。

## 10. 开工前要裁定的三件事

1. **命令语言定几条**（上表 9 条是否都进第一阶段）？
2. **决策挂点**：战略脑/战术脑是各挂一个轻量 driver，还是复用既有 `AVM`/`RocketLaunchController` 的"注册表 + 每步闭环"样板？（推荐后者，零新形态）
3. **第一阶段场景**：单舰对单舰？还是"一艘 NPC 拦截一艘无武装玩家船"（更接近 CDE 的示威/巡逻玩法）？
