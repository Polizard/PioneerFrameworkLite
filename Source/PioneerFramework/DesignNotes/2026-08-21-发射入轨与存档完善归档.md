# 2026-08-21 发射入轨与存档完善归档

> 分支：migration/dmsnf-to-pfl
> 状态：已完成本阶段开发与验证，等待后续正式化/扩展。

## 本阶段完成内容

### 1. 发射台总装流程

- 发射台燃料口改为返回中心格。
- 可建造区域恢复为中心 3×3。
- 基础火箭、基础可回收火箭占地改为 3×3。
- 建造流程改为原版 Blueprint：
  - 确认设计 → 生成 Blueprint；
  - pawn 先搬运建材；
  - 建材到位后转为 Frame；
  - 施工完成生成已完工火箭。
- 新增 `CompRocketBlueprint`，在 Blueprint 阶段携带 `RocketDesignSpec`。
- 新增 `BlueprintMakeSolidThingPatch`，Blueprint 转 Frame 时移交设计数据。
- 新增 `FrameCompleteConstructionPatch`，正常施工完成后通知发射台进入 `Completed`。
- “标记完工”调试 Gizmo 现在真正调用 `Frame.CompleteConstruction`。

### 2. 发射入轨

- 新增 `RocketLaunchConditions`：
  - 硬校验：推进器、燃料；
  - 人员校验：控制台、密封舱室（调试模式可跳过）。
- 新增 `CompRocketConsole`，供 DMS:NF 正式控制台接入。
- 发射入轨改为正式两段式圆轨化：
  - 发射后进入 92% 圆轨速度插入轨道；
  - 调用 `SpaceGameComp.BeginCircularize`；
  - 真实消耗化学工质。
- `LaunchService.ConfigureRocketPropulsion` 按 `RocketDesignSpec` 注入虚拟推进。

### 3. 存档（LA-18 部分）

- `SpaceMapComp` 持久化：
  - `RocketDesignSpec`；
  - 虚拟推进引擎参数；
  - 虚拟燃料当前存量与容量。
- 保存时自动同步虚拟燃料为工质向量中的真实剩余量。
- 读档后 `FinalizeInit` 重建虚拟推进。
- 读档后 `SpaceMapComp` 重新注册到 `SpaceGameComp.mapComponents`。
- `SpaceEntityGroup.GetLinkedMapComp` 与 `SpaceEntity.GetMapComp` 增加按 `MapId` 兜底查找。

### 4. 发射接口图标修复

- 燃料口图标在 PFL 总装发射台中心直接绘制原版 `FuelingPortCellMaterial`。
- 不再依赖原版“中心 + 右 1 格”的燃料口定位。
- 修复 `DrawGhost_Patch` 缺少 `[StaticConstructorOnStartup]` 的启动检查警告。

### 5. 存档失败修复

- 查明 `MapArchiveManager` 在封存/取出后把 `Scribe.saver / Scribe.loader` 置为 `null`。
- 修复为结束后恢复原始 Scribe 实例，避免后续存档/读档 NRE。
