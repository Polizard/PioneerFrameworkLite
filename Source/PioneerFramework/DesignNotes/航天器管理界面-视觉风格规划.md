# 航天器管理界面 — 视觉风格规划

> 状态：已实施并归档（前端 V1–V3 已落地，V4–V6 未启动）
> 日期：2026-08-22
> 性质：前端视觉重构实施手册 + 当前视觉基准。本文档基于 [航天器管理界面实施计划.md](航天器管理界面实施计划.md) §15 升级建议细化。
> 调研对象：复古未来主义 / 瑞士国际主义 / 磁带盒未来主义三种设计风格 DNA、RimWorld 原版 UI 视觉规范。DMSNF 殖民办公室仅作 §15.1 架构对比参考，不作视觉基准。

## 1. 设计哲学

PFL 航天器管理界面服务于"工业拖网渔船式航天工程"——不是银河联邦无菌洁净感，不是赛博朋克 SaaS 美学，而是 1979 年《异形》Nostromo 控制室 + 1950 年代 NASA 控制台 + 瑞士排印纪律的混合体。

**定位声明**：PFL 作为多下游 Mod 共用框架，其视觉身份不应绑定任何单一下游 Mod（如 DMSNF），而应与 RimWorld 原版 UI 视觉和谐——沿用原版暗色窗口基调、`GameFont` 字体层级、`Widgets` 标准 API，在此底色上叠加 PFL 自身的航天工程装饰语言（L 形角标、SpecBar 等），确保任何下游 Mod 引用 PFL 窗口时不产生视觉割裂。

**核心信条**：

1. **形式追随功能**（瑞士国际主义）：每个像素都为信息传达服务。装饰不是点缀，是结构。
2. **温暖近黑的厚度感**（磁带未来主义）：CRT 荧光屏辉光、暗调背景上的米色字符、磁带卡座铬色边框。技术感觉沉重、在场、有死亡可能。
3. **乐观饱和强调色**（复古未来主义）：暖铜/冷青/军绿替代霓虹紫粉。每个标签页主操作使用对应语义色。
4. **数学网格纪律**：12 列基础栅格 + 8px 基线节奏。任何 y 坐标尽量是 8 的倍数，任何 x 坐标落在栅格列上。

**视觉关键词**：工业仪表盘 / Nostromo 控制室 / NASA 1950 控制台 / Helvetica 排印纪律 / 磁带卡座铬色 / 暖调近黑屏底。

## 2. 风格 DNA 混合策略

| 风格 | 占比 | 在 PFL 中的具体体现 |
|------|------|---------------------|
| 瑞士国际主义 Swiss International | 50% | 12 列基础栅格、8px 基线节奏、单一 grotesk 字体（GameFont.Small/Medium/Tiny 系统字体替代 Helvetica）、左对齐参差、留白作为构图元素、信息层级靠字号字重而非颜色 |
| 磁带盒未来主义 Cassette Futurism | 30% | 暖调近黑背景（CRT 荧光屏辉光）、等宽终端字体用于数字读数、L 形角标、横向状态条带、磁带卷轴式装饰、URL 栏历史路径 |
| 复古未来主义 Retro Futurism | 20% | 暖铜/冷青/军绿强调色（替代赛博朋克霓虹）、原子时代几何符号（圆/抛物线/星爆）、火箭轨迹线装饰、网点纹理 |

## 4. 字体系统

### 4.1 GameFont 层级（RimWorld 原生字体替代 Helvetica）

| 角色 | GameFont | 字号 | 字重 | 用途 |
|------|---------|------|------|------|
| Display | `GameFont.Medium` | 18 | 700 | 窗口主标题"航天器管理 — 装配台" |
| Title | `GameFont.Medium` | 16 | 600 | 标签页标题"航天器总览"等 |
| Body | `GameFont.Small` | 13 | 400 | 正文、状态字段值、按钮文字 |
| Label | `GameFont.Tiny` | 11 | 500 | 字段标签"发射台状态"等（大写感） |
| Caption | `GameFont.Tiny` | 11 | 400 | 元数据、占位提示、调试日志 |
| Mono | `GameFont.Tiny` | 11 | 400 | 数字读数（PocketMapId、坐标、高度） |

### 4.2 数字读数等宽对齐

数字读数（PocketMapId #12345、坐标 (12,0,5)、目标高度 400.0 km）使用等宽风格——通过 `Text.CurFontStyle.font` 切换或固定宽度 Rect 对齐。

```csharp
// 伪代码：数字读数固定宽度对齐
private static void DrawMonospaceNumber(Rect rect, string number, Color color)
{
    Text.Font = GameFont.Tiny;
    Text.Anchor = TextAnchor.UpperRight;  // 右对齐让数字"对齐位数"
    GUI.color = color;
    Widgets.Label(rect, number);
    GUI.color = Color.white;
    Text.Anchor = TextAnchor.UpperLeft;
}
```

### 4.3 字距与行距

- 标题：`Text.Font = GameFont.Medium` 配合 `Text.Anchor = TextAnchor.UpperLeft` 左对齐
- 正文：默认左对齐，行高 22px（基于 RowHeight）
- 标签：左对齐，固定宽度 180px（栅格 6 列）
- 数字：右对齐，固定宽度 80–120px

## 5. 栅格与间距系统

### 5.1 12 列基础栅格（手算）

窗口内容区宽 760px − 安全内边距 32×2 = 696px。12 列栅格：

| 列数 | 宽度 | 用途示例 |
|------|------|---------|
| 12 列 | 696px | 全宽标题、按钮组、状态行 |
| 8 列 | 464px | 主内容卡片、列表 |
| 6 列 | 348px | 双栏布局左/右 |
| 4 列 | 232px | 信息行标签+值 |
| 3 列 | 174px | 字段标签 |
| 2 列 | 116px | 按钮宽度 |
| 1 列 | 58px | 间距、装饰 |

### 5.2 间距常量

```csharp
internal static class SpacecraftUISpacing
{
    internal const float SafePadH = 32f;
```

### 5.3 8px 基线节奏

所有 y 坐标对齐到 8 的倍数：8, 16, 24, 32, 40, 48, 56, 64, 72, 80...

```csharp
// 工具方法：将任意 y 坐标对齐到 8px 基线
private static float SnapToBaseline(float y)
{
    return Mathf.CeilToInt(y / SpacecraftUISpacing.BaselineStep) * SpacecraftUISpacing.BaselineStep;
}
```

## 6. 装饰元素库

### 6.1 L 形角标（磁带卡座铬色感）

磁带卡座铬色装饰，四角 L 形边框线：

```csharp
/// <summary>
/// 在矩形四角绘制 L 形边框线，磁带卡座铬色装饰。
/// </summary>
internal static void DrawCornerLBrackets(Rect area, Color lineColor, float inset = 6f, float arm = 14f)
{
    GUI.color = lineColor;
    float x0 = area.x + inset;
    float y0 = area.y + inset;
    float x1 = area.xMax - inset;
    float y1 = area.yMax - inset;
    // 左上
    Widgets.DrawLineHorizontal(x0, y0, arm);
    Widgets.DrawLineVertical(x0, y0, arm);
    // 右上
    Widgets.DrawLineHorizontal(x1 - arm, y0, arm);
    Widgets.DrawLineVertical(x1, y0, arm);
    // 左下
    Widgets.DrawLineHorizontal(x0, y1, arm);
    Widgets.DrawLineVertical(x0, y1 - arm, arm);
    // 右下
    Widgets.DrawLineHorizontal(x1 - arm, y1, arm);
    Widgets.DrawLineVertical(x1, y1 - arm, arm);
    GUI.color = Color.white;
}
```

### 6.2 横向状态条带（SpecBar 风格）

3px 实色条 + 主色左边条 + 标签文字。用于状态机当前态、发射台状态行。

```csharp
internal static void DrawSpecBar(Rect r, string text, Color accentColor)
{
    const float strip = 3f;
    Widgets.DrawBoxSolid(r, SpacecraftUIPalette.SpecBarBg);  // #1C222C
    Widgets.DrawBoxSolid(new Rect(r.x, r.y, strip, r.height), accentColor);  // 主色左边条
    Rect textR = new Rect(r.x + strip + 6f, r.y + 6f, r.width - strip - 10f, r.height - 12f);
    DrawColoredLabel(textR, text, SpacecraftUIPalette.SpecTextTitle, GameFont.Small, TextAnchor.UpperLeft);
}
```

### 6.3 网格线背景（磁带未来主义线框网格）

```csharp
internal static void DrawLightGrid(Rect area, Color lineColor, float step = 40f)
{
    GUI.color = lineColor;
    for (float x = area.x; x < area.xMax; x += step)
        Widgets.DrawLineVertical(x, area.y, area.height);
    for (float y = area.y; y < area.yMax; y += step)
        Widgets.DrawLineHorizontal(area.x, y, area.width);
    GUI.color = Color.white;
}
```

### 6.5 序号标签（#01 / #02 两位数前缀）

设计页 Part/载荷列表项使用两位数前缀。

### 6.6 网点纹理（复古印刷感）

1px 点阵步进 8px 半透明，用于卡片背景。

```csharp
internal static void DrawDotGrid(Rect area, Color dotColor, float step = 8f)
{
    GUI.color = dotColor;
    Texture2D tex = BaseContent.WhiteTex;
    for (float x = area.x; x < area.xMax; x += step)
        for (float y = area.y; y < area.yMax; y += step)
            GUI.DrawTexture(new Rect(x, y, 1f, 1f), tex);
    GUI.color = Color.white;
}
```

```csharp
        internal static readonly Color SpecWarmCopper = HexRgb("#D48C3C");
        internal static readonly Color SpecWarmCopperHover = HexRgb("#E4A060");
        internal static readonly Color SpecColdCyan = HexRgb("#3A8A7A");

        internal static readonly Color SpecMilitaryButton = HexRgb("#5A7A4A");
        internal static readonly Color SpecDanger = HexRgb("#E76F51");
        internal static readonly Color SpecAmber = HexRgb("#F4A261");

        private static Color HexRgb(string hex)
        {
            if (hex.Length >= 7 && hex[0] == '#')
            {
                int r = HexNibble(hex[1]) * 16 + HexNibble(hex[2]);
                int g = HexNibble(hex[3]) * 16 + HexNibble(hex[4]);
                int b = HexNibble(hex[5]) * 16 + HexNibble(hex[6]);
                return new Color(r / 255f, g / 255f, b / 255f, 1f);
            }
            return Color.white;
        }

        private static int HexNibble(char c)
        {
            if (c >= '0' && c <= '9') return c - '0';
            if (c >= 'a' && c <= 'f') return c - 'a' + 10;
            if (c >= 'A' && c <= 'F') return c - 'A' + 10;
            return 0;
        }
    }
```
