外围“单点取数”文件清完后（Piloting / Feedback / RadarSweep 归零），剩余 **21 文件 / 122 处** 全部挂在
`MainTabWindow_PFView` 的**主取数路径**上：窗口用 `selected = space.GetGroupById(selectedGroupId)` 拿到组对象，
然后把它传给 `ToggleManualSteering` / `DrawNetworkSelectorButton` / `TrySeparateStage` / `SetAutoStage` /
`ResolvePilotFollowFrame` 等一长串 helper。

**2026-11-01 01:3x 复核（重要）**：`Inspector` 也不能单独清——它虽然只 8 处引用，但 `selected` / `source`
（`ResolveOperationGroup()`）这两个组对象被 `CanOperateGroup` / `ToggleManualSteering` / `TryOpenWeaponsFor` /
`DrawNetworkSelectorButton` / `ShowGroupMapMenu` / `TrySeparateStage` 共享，**改一个就要改一串**。
`Inspector` 的舱室列表还要 `SpaceMapGenerator.GenerateRoomMap(entity, part)`（需要对象）⇒ 只能走命令：
`PhysicsCommands.EnterRoomMap(groupId, partId)`。
所以剩余 19 文件是一个**整体**，逐文件迁移会在 `Inspector` 这一步再次撞墙。

**这不是逐文件替换能做完的**，建议作为一轮独立重构（需游戏内验证）：

1. **命令面补齐**：`PhysicsCommands.SeparateStage(id) → (newId, reason)`、`SetAutoStage(id, bool)`、
   `SetSteering(id)`、`SelectBurnNetwork(id, ...)`；
2. **查询面补齐**：`CopyLinkedMapIds`、`CopyNetworkOptions`、`CopyRoomParts`（舱室）、
   `TryCollectTelemetry`（部件健康/地图/武器/Δv/续航的聚合）；
3. **主窗口取数改 id + 快照**：`selected` 局部对象 → `(selectedGroupId, SpacecraftSnapshot)`，
   逐一把 helper 签名改成 id；
4. 每改一组跑 `check-architecture` + 全量闸门，最后进游戏验收 PFView（选中/编队/雷达/检查器/驾驶面板）。

在完成前，`architecture-baseline.json` 继续当棘轮：只许降，不许升。
