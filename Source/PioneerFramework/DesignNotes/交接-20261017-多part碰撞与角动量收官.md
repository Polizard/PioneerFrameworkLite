## §1 本线完成清单

### 1.1 转动 / 数学（前置批）
- **转动批 1（魔法档限速）**：`ω_max = clamp(τ_ref / I_轴, 0.2°/s, 30°/s)`；锚点 = 默认无Map船（5000 kg、40×20×80、最慢轴 I≈3.333e6、τ_ref≈290,888）；逐轴 `nᵀ·I_com·n`；def 覆盖（导弹 20°/s）。
- **KSA-①**：`BurnRefineNewton`（2-DOF 牛顿 + 半步回退 + 五条护栏；net48 兼容），`BurnArcCompensation` 牛顿优先、原网格兜底；**暂无生产调用者（latent）**。
- **KSA-②**：`BurnArc` 自适应步数 `clamp(ceil(970·t_b/T_loc), 50, 400)`，`T_loc=2π√(r³/μ)`；相位测试 20/20 绿。
- **KSA 全线收官**：见 `DesignNotes/KSA线收官-20261017.md`；燃烧换律实验裁定「沿用我们自己的律」（RTN），4.8× e 挂账留在我们账上。

### 1.2 普适多part 架构
- `ShipPartDef`（普适零件目录，**不是火箭专用**）· `DesignPartSpec`（设计引用）· `DesignPartAssembler`（舱盒 Part[0] + 追加件沿 −Y 堆叠；cap 64；`linkedMapId=-1`）。
- `SpacePart` 列表挂在 `SpaceEntity` 上；`Map` 住在 part（`linkedMapId`）；`TryPickHitPart` 逐 part 最近命中；地图映射只对 `linkedMapId>=0`。
- `LaunchService` 只追加目录命中（`includeUnknownDefs:false`）⇒ 既有 DMS 设计保持单 part。
- XML：`<ShipPartDef Class="PioneerFramework.ShipPartDef">`（RimWorld 的 `DefFromNodeNew` 只按简单类名解析）。

### 1.3 真碰撞 / 响应
- 窄相取**最深 part 对**：最小穿透轴、深度、接触点；**2026-10-17 用户裁 A**：两支都有可用 part 时无 part 对 ⇒ 不解析（并集盒空角不算接触），仅一方无可用 part 才回退组级 AABB（§8.6）。
- 碰 1/5/7/8：最小穿透轴 · 质量反比分离 · `e=0.2`（<1 m/s 非弹性）· part 级 `noCollide`。
- 角冲量：`Δω = I⁻¹(r×J)`，经惯量张量主轴/方向矩阵；本轮修复 **COM 未旋转**（§2.1）。
- 高速：相对扫掠盒 + 相对 TOI + 一步跨过侧别翻转；分离方向用**翻转前**的当前 A→B（`nSep`），冲击法线用侧别翻转后的 `nDir`；爆炸分支增加 `e=0.2` 法向冲量（修「粘住」）。
- tunneling 黏着回环：移除 `pbPrev` 回退；起点已在膨胀盒内/正在分离 ⇒ 不重算停点。

### 1.4 窄相性能全栈（多part 一次做透）
- **O(nA×nB) 次姿态变换 → O(nA+nB) 次**：每件 part 只做一次 `GetPartAabbSystem`；旧实现把 B 的变换放在 A 的 part 循环内。
- **组级 part AABB 缓存**：跨 tick 复用对象；`epoch` 失效；每 600 步 prune；同一 tick 与多个对手窄相只收集一次。
- **裁剪盒剔除**：只保留与「两组 AABB 交集」有正重叠的 part；长船端部相碰 256×256 从全量降到约 6×6。
- **自适应 SAP**：`nA×nB > 512` 走 sweep-and-prune（最大跨度轴、起止事件、活跃集、`ArrayPool` 零 GC）；更小走两两比较。
- **AabbOverlap 逐轴早退**；旋转矩阵按姿态缓存（只随 `Rotation` 失效）。
- **并列深度**按 `(A.Order,B.Order)` 取最小，SAP/裁剪结果与嵌套循环**逐位一致**。
- **BVH 原型**：已实现并实测，512/1024 稀疏与稠密均慢于 SAP ⇒ **判过不接**，仅 `forceBvh` 台架入口保留作为证据（读数 §3.2）。

### 1.5 新一键验收
`ComplexCollisionAcceptanceRunner`（`Base/Debug/ComplexCollisionAcceptanceRunner.cs`）：
- 4 组**独立场地**、不同角度/姿态/偏置的复杂多part 船对（7–8 个 part，非对称质量/位置）：
  - S1 对称正撞（应零转）· S2 Y 偏置 · S3 双旋转/斜向 · S4 长船侧擦。
- 速度 1.5 m/s（低于爆炸阈值，隔离爆炸）；自动强制 1×；Stage 前清理上一轮遗留组；结算后清场。
- 判据：part 窄相 / 冲量公式 / 撞击后速度 / Δω 落到组 / 头对头零转 / 偏置非零 / **总角动量守恒** / 只撞一次。
- 碰撞记录：`CombatManager.CaptureCollisionRecords`（生产 false），记录接触点/法线/冲量/Δω/姿态/质量，供验收用。

## §2 本轮关键修复（都是测试/日志逼出来的）

### 2.1 角冲量杠杆未旋转 COM（★真 bug）
`ComputeCollisionDeltaOmega` 原先把 `r.comX/Y/Z`（**船体系**质心）直接当世界系减掉：

```csharp
leverWorld = worldContact - groupPos - new DVector3(r.comX, r.comY, r.comZ);
```

船一旋转，杠杆臂就错；S3 的 L 相对误差 **1.92E-2**。已改为：

```csharp
DVector3 comWorld = DVector3.Rotate(new DVector3(r.comX, r.comY, r.comZ), rotation);
leverWorld = worldContact - groupPos - comWorld;
```

修复后 S3 L → **1.98E-7**，S4 → **6.49E-7**；S1 的 COM 在原点，始终 1e-18 量级。

### 2.2 高速「粘住」/反复爆炸
- 移除 `ResolveTunneled` 末尾的 `ApplyTunneledStop(b, pbPrev)` 回退；起点在膨胀盒内/`vRel<=0` 时不重算停点（否则每 tick 把 B 拖回 A 的新表面）。
- 爆炸分支加 `e=0.2` 法向冲量（此前 e=0 会把双方压成同速粘在一起）；`SeparatePositions` 用 `nSep`（当前 A→B），冲击法向用 `nDir`。

### 2.3 验收自身的坑（已修）
- **重力累积**：原先在最终结算才读实际速度，S1 差 0.34 m/s；改为撞击后 10 tick 内采实际速度/角速度。
- **记录 A/B 互换**：碰撞枚举顺序不保证；S4 曾以 B-vs-A 记录，L 算成 2.39；`CountRecords` 现在把记录翻回场景 A/B。
- **缺失组**：`PflTestKit.Unchecked` 会当场结束整个用例；改为最后统一判 UNCHECKED，S3/S4 的判据不再落在“没有用例的地方”。
- **旧组叠场**：Stage 前按 `spawnedGroupIds` 显式销毁上一轮；防两套船同场导致多次接触。
- **深穿透连撞**：接近速度 3→1.5 m/s，单步位移 3m，减少多part 深穿透的连续接触；超时 7200 tick。

## §7 本轮新增纪律（测试/施工）

- **一键验收必须自己推进物理**：用户可能在暂停/0× 下点按钮；Stage 强制 1×（`DesiredTimeScale=Normal` + `TimeScaleManager.SetNormalMode` + `TimeSpeed.Normal`）。

- **记录 A/B 顺序不保证**：任何按记录判角动量的验收都必须按场景 ID 归一化。
- **缺失样本用 `PflTestKit.Unchecked` 会结束整个用例**：多个子场景应在最后统一判。
- **低速复杂碰撞的深穿透**：接近速度/场景几何要保证首个接触法线是预期轴；否则最小穿透轴可能选错轴（S1 已用宽 Y/Z 对称船规避）。
- **测试场景独立场地**：多组对撞按 y 隔开（本验收用 1.2e9 + i·2e8），避免爆炸/冲击波跨场污染。
- **演示日志自动关**：碰撞演示 30s 后自动关 `DebugDetailedCollision`；手动按钮仍在。

台架（Release，256×256 长堆叠，`CollisionContactBench`）：

| 项目 | 优化前 | 优化后 |
