## 0. 目标与非目标

### 目标
- 一种**不产生 3D 物理射弹**的炮塔：开火瞬间即命中目标（定向能/光束）。
- 命中后：目标 Part 伤害 + 目标 Map 上**贯通视觉弹**（入口在 Map 边缘，极速贯穿到命中格，"一条光束切进船体"）。
- 3D 侧保留光束视觉残留（`LaserBeamInstance`，60 tick 淡出）。
- 全链路接入现有基础设施：定位机索敌 → 整体式炮塔 → 出膛点 → 即时判定 → Map 落点。

### 非目标（本阶段不做）
- 穿透命中多船（遮挡语义：**只命中最近一艘**）。
- 光束偏转/拦截/护盾。
- 激光落点范围伤害与 pawn 伤害（沿用现有 `SpawnPenetrationMote` 落点建筑伤害语义，范围伤害仍在炮塔记录待办 #1）。
- 弹药链（`ammo` 保持无限）。

## 1. 核心架构决策

### 1.1 不生成 3D 射弹（与射弹炮塔的本质区别）

| | 射弹炮塔（Projectile） | 定向能炮塔（Ray） |
|---|---|---|
| 物理对象 | `ProjectileInstance` 入 CombatGrid | **无**（开火瞬间结算） |
| 检测时机 | 每 2 tick，对每发在飞射弹 | **仅开火那一瞬间**，一次性 |
| 飞行时间 | 有（弹速 5km/s，需提前量） | **零**（即时命中，无需提前量） |
| 命中几何 | 目标参考系（同轨高速，tunneling 防御） | 当前时刻世界系 slab 求交 |
| 时间流速 | 自动降 Combat 档（子弹时间） | 不触发 |

> 结论：定向能的检测成本是**每发一次性的**，比射弹炮塔"每 2 tick × 每发在飞"便宜一个量级。高速射弹检测的那套复杂度（目标参考系回退、segmentLength 防御、子弹时间）在定向能路径上**根本不会出现**。

### 1.2 检测方式 = 细网格正方体粗筛 + 射程过滤（A）∥ 细网格 DDA 走格（B，预留）

```
输入：spawnPos（出膛点世界坐标）、direction（世界系单位向量）、beamLength（光束长度）
endPos = spawnPos + direction × beamLength
候选收集（A）：
  ① 正方体粗筛：以 spawnPos 为中心、边长 2×beamLength 的正方体，收集其覆盖的
     战斗区块（CombatGrid 细网格 20km）内的所有船
  ② 射程过滤：dist(groupPos - spawnPos) ≤ beamLength（球内）
  ③ 过滤敌对/IsActive/IsCollidable → slab 最近命中（遮挡语义）
走格工具（B，预留）：CombatGrid.GetShipsNearSegment 薄封装（线段 DDA，候选更精确），
         射线当前不调用，等射程/规模变化或需要更紧候选时切换（切换点已留好，见 T2）
```

**为什么用战斗区块而不是粗网格 8 大区块**（2026-08-29 用户拍板）：
- 激光射程 50km 量级，正方体边长 2R=100km。粗网格大区块 1000km，正方体只压 **1** 个大区块，而整个月球系战场几十艘船都在同一大区块内 → 粗筛≈没筛。
- 战斗区块 20km：正方体覆盖 5×5×5=125 个细格，但**每格船少**（0-1 艘），粗筛后候选 ≈ 射程内实际船数。125 次字典查找（多数 miss）换取候选精确。
- **取舍边界**：正方体覆盖格数 ≈ (2R/20)³。射程 < ~100km 细网格优；到 200km 变 20³=8000 格爆炸，届时切粗网格（≤8 大区块）或线段 DDA（B）。格数按区间动态计算，无需硬编码。
- 复杂度：A = O(覆盖细格数 + 射程球内船数)；B = O(线段跨格数 + 每格船数)。两者收敛到同一个精确判定（slab + part）。

### 1.3 最近命中（遮挡语义，已确认）

- 光束沿直线飞行，路径上多艘船时命中 **tEntry 最小**的那一艘（与现有 `FireRayWeapon` 的 closestT 逻辑一致）。
- 命中后光束结束（不穿透），视觉残留 `LaserBeamInstance` 端点 = 命中点。

### 1.4 Map 落点贯通视觉弹（已确认）

- 命中目标 `entity.MapId >= 0` 时，在目标 Map 生成 `PFProjectile3D` 贯通视觉弹：
  - **入口点** = 命中点沿入射方向**反方向**延长到船体 AABB 六面（`MapCoordMapper.RayExitAabb` 反向复用，与出膛点几何对称）。
  - **落点** = 命中点映射格（现有 `ShipLocalToMapWorld`，y=0）。
  - `Launch3D(start=入口, end=落点, speedOverride=大值)` → 1~2 tick 贯穿，视觉是光束切进船体。
- 实现方式：给 [SpawnPenetrationMote](file:///d:/PioneerFrameworkLite/Source/PioneerFramework/Combat/CombatManager.cs#L1467) 增加**可选入口点参数**；F3 射弹命中继续传"入口=落点"（瞬爆，现状不动），定向能传贯通入口。

### 1.5 光束视觉（已有）

- 命中/未命中都追加 `LaserBeamInstance`（60 tick 视觉残留，`systemBodyId` 已贯通渲染）。
- 光束颜色沿用 `WeaponDef.beamVisualColor`。

## 2. 射线检测优化专题（本设计的核心疑虑）

用户担心的"射线检测优化" = **定向能即时命中判定（raycast：光束与战场求交）怎么做又快又准**。结论拆成"快"与"准"两面：

### 2.1 "快"：瞬态成本 + 战斗区块正方体粗筛

| | 射弹炮塔（每 2 tick） | 定向能（每炮一次） |
|---|---|---|
| 检测频率 | 每 2 tick × 每发在飞（可能 30+ 发） | **开火那一瞬间，一次** |
| 单次成本 | 细网格 DDA 走格 + 候选 slab | 细网格正方体（~125 格）+ 射程过滤 + slab |
| 持续负担 | 高（战场全程） | **瞬态**（打完即走） |

- 定向能 raycast 是**瞬态成本**：正方体粗筛（125 次字典查找，多数 miss）+ 射程球内船数 slab，一炮成本可忽略。
- **粗筛正确性前提**：战斗区块（CombatGrid 细网格）位置由 `SyncAllShipsToGrid` 每 2 tick 更新（射弹检测同源，天然新鲜）；不依赖粗网格位置。
- 真正值得投入优化的持续成本在**射弹炮塔那条链**（每 2 tick × 每发在飞），不在定向能这里。

### 2.2 "准"：正确性优先于性能（本设计真正要做的事）

现 [FireRayWeapon](file:///d:/PioneerFrameworkLite/Source/PioneerFramework/Combat/CombatManager.cs#L1546) 的暴力遍历骨架可以保留，但有两个正确性缺陷必须修：

1. **part 检测旋转**：现有实现用"世界方向在局部系延伸"（`localOrigin + dir*maxDist`），船无旋转时恰好成立，旋转时失效。→ 照 [CheckSegmentGroupHit](file:///d:/PioneerFrameworkLite/Source/PioneerFramework/Combat/CombatManager.cs#L404) 的完整旋转处理写。
2. **遮挡语义**：现有 closestT 逻辑方向正确，但候选来自 `GetAllGroups()` 全量（含非敌对），需改为战斗区块正方体候选 + 射程过滤 + 过滤条件与射弹检测一致（敌对/IsCollidable/IsActive）。

### 2.3 与已弃置 `multi_projectile_optimization.md` 的关系

- 该文档的 Morton 化 / 全局 Part Morton / 跳表，属于"上百艘船混战"量级，Lite 当前不引入。
- 其中"优化二（完整 DDA）"已在 `GetShipsNearProjectile` 落地，是 B（走格预留）可直接复用的基础。

### T2：CombatManager 改造 `FireRayWeapon`（核心改动，A 起步）

- 光束长度：`weapon.def.maxRange`（Ray 语义 = 光束长度；Def 与 `orbitalEngageRange` 对齐，50km 量级）。
- **候选（A）**：`combatGrid.CollectShipsInCube(射手参考系, spawnPos, beamLength, 候选集)` → 射程过滤 `dist ≤ beamLength` → 过滤 `IsActive && IsCollidable && 敌对`。
- **候选（B，预留切换点）**：将来替换为 `GetShipsNearSegment` 走格结果，精确判定循环体不变——把"取候选"抽成一个私有方法 `CollectRayCandidates(...)`，A/B 两种来源都汇入同一个 HashSet，切换只改一行。
- 精确判定：对每个候选 group，**当前时刻** `GetGroupPos(group)` + Entity AABB（`±AabbHalfSize`）→ `RaySlabIntersection(startPos, endPos, ...)` → 取最小 `tEntry`（遮挡语义）。
- Part 级检测：**照 [CheckSegmentGroupHit](file:///d:/PioneerFrameworkLite/Source/PioneerFramework/Combat/CombatManager.cs#L404) 的旋转正确版**写（命中点 → 局部系 → part slab），不照抄旧 `FireRayWeapon` 的"世界方向在局部系延伸"简化版。
