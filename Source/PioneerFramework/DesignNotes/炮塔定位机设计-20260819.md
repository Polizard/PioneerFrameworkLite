# 先驱框架Lite（PFL）Map 炮塔定位机设计

## 1. 背景（Problem）

PFL 的战斗链路完整（`CombatManager` 射弹 / 命中 / 提前量），但武器来源缺失：`groupWeapons` 是等待填充的空容器（[CombatManager.cs](../Combat/CombatManager.cs) 注释）。空间站对射是核心玩法，需要把 **Pocket Map 上的炮塔建筑** 与 **3D 射弹** 桥接起来。

SOS2but2D 的设计精髓：**索敌逻辑集中到「定位机」建筑一处，N 个炮塔共享同一套目标判定，炮塔只当发射锚点**。本设计照搬该架构，并针对 PFL 的 3D 轨道语境重构。

## 2. 架构总览

```
Pocket Map（= 船）
  ├── CompMapDesignator（定位机：索敌大脑，一个管一组炮塔）
  │      ├─ 索敌: 遍历敌对 3D group → 半球射界过滤 → 距离判定
  │      ├─ 统一冷却 → 齐射
  │      └─ 驱动绑定锚点转向
  └── CompMapTurret × N（炮塔建筑：纯锚点）
         └─ TurretMount 列表（每锚点独立 WeaponInstance / 朝向 / 定位机绑定）
                └─ CombatManager.FireFromMapBuilding → 复用 FireWeapon 链路 → ProjectileInstance
```

## 3. 组件设计

### 3.1 CompMapTurret（炮塔建筑，锚点）

文件：`Base/Buildings/CompMapTurret.cs`

```csharp
public class CompProperties_MapTurret : CompProperties
{
    public string weaponDefName;       // WeaponDef 名
    public TurretMountSide mountSide;  // Both / Top / Bottom
    public float yOffset = 25f;        // 炮口相对船体表面在局部 Y 的偏移（米）
}

public enum TurretMountSide { Both, Top, Bottom }

public class CompMapTurret : ThingComp
{
    private List<TurretMount> mounts;  // PostSpawnSetup 按 mountSide 生成
}

public class TurretMount
{
    public TurretMountSide side;       // Top / Bottom（锚点个体）
    public WeaponInstance weapon;      // 独立状态机（冷却/过热/弹药，ammo 默认无限）
    public float rotation;             // 朝向角（船体局部系，度）
    public Thing boundDesignator;      // 绑定的定位机建筑
}
```

- **三种安装类型**：`Both` 生成 2 个锚点（上 + 下）；`Top` / `Bottom` 各 1 个。
- **渲染**：只渲染含 `Top` 的锚点（`Both` 也只画上炮）。朝向无反射——用原版 `Graphic` 的 `extraRotation` 参数：

```csharp
public override void PostDraw()
{
    base.PostDraw();
    if (topGraphic == null) return;
    topGraphic.Draw(parent.DrawPos, Rot4.North, parent, currentRotation); // 任意度数
}
```

- **Gizmo**：绑定 / 解绑定位机（FloatMenu 列出本地图同 faction 定位机）；`Both` 型提供「绑定上炮 / 绑定下炮」两个入口。
- **不引入反射**：SOS2 因复用原版 `Building_ShipTurret` 被迫用反射读私有 `top` 字段；PFL 炮塔是自建 `ThingDef`，朝向是 Comp 内 float + 自绘，无反射。

### 3.2 CompMapDesignator（定位机，索敌大脑）

文件：`Base/Buildings/CompMapDesignator.cs`

```csharp
public class CompProperties_MapDesignator : CompProperties
{
    public int cooldownTicks = 60;     // 统一齐射冷却
    public int scanIntervalTicks = 32; // 索敌扫描间隔
}

public class CompMapDesignator : ThingComp
{
    private List<TurretBinding> boundMounts;   // { Thing turret; TurretMountSide side; }
    private DesignatorMode mode;              // Manual / Auto
    private int manualTargetGroupId = -1;      // Manual 模式指定的敌对 group
    private int cooldownTicks;
    private bool autoFire = true;
}
```

- **模式**：
  - `Manual`：玩家指定敌对 group（Gizmo 从雷达/目标列表选择），射程内持续开火。
  - `Auto`：自动索敌**最近的敌对 group**（≤ `orbitalEngageRange`）。
- **索敌**（每 `scanIntervalTicks`）：遍历 `SpaceGameComp.GetAllGroups()`，条件：
  - `IsActive && IsCollidable`
  - 敌对 faction（`group.FactionId` 与定位机所属船不同）
  - 世界距离 ≤ `orbitalEngageRange`
  - **半球射界**：每个绑定锚点单独判定（见 §4）
- **齐射**（统一冷却到）：对每个**射界内**的绑定锚点：`weapon.Fire()` → `CombatManager.FireFromMapBuilding(...)`。
- **序列化**：`PostExposeData` 落盘绑定关系（Scribe 引用）、模式、手动目标。

## 4. 坐标换算（关键：船在 3D 空间有朝向）

`SpaceEntity.Rotation`（`Quaternion`）为船姿态，**所有局部↔世界换算必须过它**：

```csharp
// 1. 锚点世界位置（炮口）
muzzleWorld = groupPos + entity.Position + entity.Rotation * (localXZ + (0, ±yOffset, 0));
//   localXZ = MapCoordMapper.MapCellToLocal3D(炮塔格)

// 2. 射界判定（船体局部系，船翻转后世界 +Y 不再是"上方"）
targetLocal = Quaternion.Inverse(entity.Rotation) * (targetWorld - (groupPos + entity.Position));
Top:    targetLocal.y > muzzleLocalY;
Bottom: targetLocal.y < muzzleLocalY;

// 3. 炮塔朝向角（地图平面 = 船体 xz 平面，贴图直接可用）
localDir = Quaternion.Inverse(entity.Rotation) * (targetWorld - muzzleWorld);
angle = Mathf.Atan2(localDir.x, localDir.z) * Mathf.Rad2Deg;
```

## 5. 半球射界与锚点独立性

- 上锚点射界 = 船顶半球（局部 +Y），下锚点 = 船底半球（局部 -Y）。
- 目标几乎不可能同时在船顶与船底 → **上下锚点分开绑定定位机**，各自索敌、各自开火（`Both` 型 = 2 个锚点 2 门炮，仅渲染上炮）。
- 绑定粒度 = 锚点：`RegisterTurret(Thing turret, TurretMountSide side)`。

## 8. F3 扩展：命中 → Map 三维贯穿弹道（Mote）

> 从「命中→坐标映射→瞬间爆炸」升级为**完整贯穿叙事**：3D 射弹命中船体后，船内（Map 场景）能看到一发炮弹沿真 3D 路径破壁飞来，落点爆炸。Map 场景本质是 Unity 3D 场景（`Thing.DrawPos` 含 y 高度），三维飞行是现成能力。

**路径来源（现成）**：`CheckSegmentGroupHit` 已计算射弹进入 Part AABB 的 `tEntry`：

```
入口点 = startPos + worldDir * tEntry（3D，船体外壁）
命中点 = hitEntryPoint（3D，Part 内）
路径   = 入口点 → 命中点（船体局部系中的 3D 直线）
```

**映射**：路径两端经 `MapCoordMapper.ShipLocalToMapWorld`（xz = 格映射，y = 船体高度分量）→ Map 场景 3D 坐标。

**生成**：目标 Map 上生成 `MoteThrown`，`exactPosition` 从入口点开始，`velocity` = 3D 方向 × 表现速度（时间放大：3D 穿透是瞬间，Map 内表现 0.5~1s）。Mote 自带 alpha/scale 曲线，可做"越飞越亮、落点爆闪"。

**落点**：Mote 到达命中点映射格 → 销毁并触发落点爆炸视觉（复用现有爆炸/视觉残留）。3D 侧伤害仍在命中瞬间即时结算，二者同步叙事。

**性能结论**：Mote 优于原版 Projectile（重：thing 列表/格物理/命中检测/ThingDef）与自定义 DrawMesh（每颗每帧一次 Draw Call + 手写生命周期）。空间站对射 = 少量炮弹短飞行，Mote 是语义 + 性能双最优。
