# 操舵与推进朝向设计（PFL 手动机动链）

> 施工状态 2026-08-30：M-a ✅ → M-b ✅ → M-c ✅ → **D13 矢量 RCS ✅** → **D14 交会精度 ✅（游戏内验证通过：弱 RCS 下 dist 收敛正常）** → M-b2 ⬜ → M-d 收尾中（Release 编译通过、80+12 测试全绿）。
> 实现注记：① 自动对准是「burn 内部融合」而非独立前置状态（StartBurn 调用点零改动，未对准时 burn 只转不推，行为等价 D5）；② 显式转向机动（kind=Turn）与时间前滚未做，见 M-b2；③ 动作组按 def 级 `actionGroups` 掩码（逐引擎过滤手动指令），UI 编组后置；④「需有人操作」开关未实现（默认关）。

> 定位：给「单 part 船/空间站」补齐两个缺失维度——**转动**（魔法动量轮）与**推进朝向**（六方向引擎判定），并接入 KSP 式手动机动（操舵台 + 动作组）。
> 前置：dV 体系（burn / 机动队列 / 交会 / 轨道保持）全链已验证。本文在其上补朝向约束，**不改工质 / 推力数值模型**（ve·ṁ 体系原样保留）。

---

## 0. 目标与非目标

### 目标
- 船可以转动：动量轮**直接叠角速度**，不做转动惯量。
- 推进看朝向：Map 推进器区分**六方向**；机动与手动指令**只用能朝目标方向出力的引擎**。
- 矢量锥判定（默认 **10°** 半锥），机动对准判定放宽。
- 自动机动（机动队列 / 交会 burn）**先自动转向再点火**（SAS 式）；转向可作为**机动队列一等公民**显式排队并预留执行时间（D12）。
- 操舵台建筑解锁操舵 + **动作组**（1-9）按键绑定，KSP 式手动机动。
- 旋转**参与碰撞**：part 盒随 rotation 转成世界 AABB，slab / 扫掠检测照用。

### 非目标（本阶段不做）
- 转动惯量 / 扭矩物理。
- 动量轮耗电（操舵台与动量轮都不接电力闭环，功能解锁即生效）。
- **撞击角速度扰动**（碰撞只做平移分离；角速度只由操舵 / 动量轮产生）。
- 无 Map group（穿梭机 / 导弹）的姿态约束——一律视为**全矢量**推进。
- 推进器锥角差异之外的任何新推力模型（F = ve·ṁ 不变）。

## 1. 现状（为什么船缺这两样）

| 痛点 | 现状证据 |
|---|---|
| 推进不看朝向 | `StartBurn(dV)` 只存世界系方向（`SpaceEntityGroup`），每物理步 `pendingImpulse += burnDirection·dv`，推力大小取**全网络聚合**，不检查引擎能否朝该方向出力——侧着也能烧 |
| 引擎列表无方向 | `SpaceMapComp.RegisterEngine(def, ve, mf)` 按工质纯数值聚合；`thrusters` 列表仅用于喷焰表现 |
| 船不能转 | `OrbitState.rotation` 存在且已序列化，但全项目**无人消费**（3D 战斗视图拿速度方向当船头） |
| 碰撞盒不随旋转 | part AABB = `localPosition ± localBoundsSize/2`，世界轴对齐，无旋转参与 |

> 好消息：数学底座已就绪——`DVector3.Rotate` / `DQuaternion.AngleAxis` / 四元数乘法（`Base/Core/DVector3.cs`），转动积分可直接做。

## 2. 核心架构决策（2026-08-29 已收敛）

### D1 六方向坐标系
- 船体局部系：**Map +X → 船 +X，Map +Z → 船 +Z，船 +Y = 世界 Y**（地图是水平切片）。
- 推进器方向 = def 的 `thrustAxis`（六向枚举）+ 建筑 `Rot4`（XZ 四向随旋转映射；Up/Down 忽略 Rot4）。
- 这样上/下引擎在 2D 地图上也能摆，现有推进器 Def 只需补一个字段。

### D2 MapComp 引擎列表改造（per-axis 聚合）
- `IPropulsionSource` / 工质网络**契约不动**（dV、ve、工质消耗逻辑全保留）。
- `PropellantNetwork` 增加 `thrustByAxis[6]` / `flowByAxis[6]`，注册时按 (工质, 轴向) 记账；现有 Σ 聚合（`EffectiveVe` / `Thrust`）保留。
- burn 活动网络 = **轴向 ∩ 工质**双重过滤（与现有 `burnEnabledNetworks` 串联）。

### D3 旋转积分（魔法动量轮）
- group 新增 `DVector3 angularVelocity`（rad/s，序列化）+ `maxAngularRate` 限速。
- 每物理步：`rotation = DQuaternion.AngleAxis(|w|·dt, w) * rotation`。
- **并行只读纪律**：与 `pendingImpulse` 一致，rotation 更新走 `GroupPhysicsResult` 回传 + 主线程 `UpdateGroupOrbit` 统一施加。
- 大步长（物理步 2s）下角速度积分用多子步，避免肉眼可见跳变。

### D4 矢量锥 + 方向感知推力
- 每个推进器一个锥角（def 字段，**默认 10°** 半锥）。
- 统一方向查询：`GetThrustAlong(dir, rotation, coneCos, propellantFilter)`：
  - Map 源：遍历 6 轴，`dot(worldAxis, dir) ≥ cos(锥)` 的引擎聚合出力；
  - 全矢量源（无 Map）：直接返全部网络聚合。
- **机动 burn 以主推进方向引擎为主**，矢量锥内其它轴向引擎辅助出力。
- 手动平移（6 向键控）与自动 burn 走**同一个**方向感知函数。

### D5 自动对准 + 点火状态机（Align 执行器）
- 机动点火不再直接 `StartBurn`，先进入 `Align → Burn → End` 状态机：
  - **Align**：每物理步算最短旋转（`axis = cross(mainAxisWorld, burnDir)`），按 `maxAngularRate` 限速逼近；夹角 ≤ 10°（锥角）→ 进入 Burn；
  - **Burn**：现有逻辑，活动网络只取锥内主方向引擎；
  - 状态字段 `pendingAlignDir`（待对准的 burnDir，序列化）。
- **Align 执行器 = 转向机动（D12）与自动对准兜底共用**。
- 自动对准本质是**消旋控制器**，顺带把残余角速度拉回零。

### D6 无 Map group 全矢量
- 穿梭机 / 导弹没有地图没有引擎朝向 → 视为内置 RCS / 动量轮，**任意方向可推力**。
- `GetThrustAlong` 对这类源直接返回全网络聚合 → 跳帮引导零改动。

### D7 操舵台建筑 + 动作组
- 新建筑 `CompSteeringConsole`（ThingDef `designationCategory=Power`，按项目约定）。
- **打开方式**：选中建筑 → Gizmo「打开操舵」→ `Window_Steering`（沿用项目 `CompGetGizmosExtra` + `Command_Action` 开窗模式，同 CompShuttleDock）。
- **激活条件**：船上存在 ≥1 台完好操舵台 → 激活；**「需有人操作」设置默认关**——开启后需指派 pawn 站台操作（对齐 SOS2 舰桥分工；工作类型可后置）。
- **界面形态**：独立窗口、**HUD 样式**（半透明紧凑、默认贴屏幕角落、可拖动/收放）；打开时吞键（`Event.current` KeyDown/KeyUp），ESC 关闭释放。
- **键位（固定，UI 图示标出）**：
  - 平移：W/S/A/D + R/F（6 向，按住持续出力）；
  - 旋转：Q/E 滚转 + 方向键偏航/俯仰，动量轮直设角速度；
  - 动作组 1-9：引擎编组、按键切换武装。
- 窗口内容：姿态区（当前朝向 vs 顺向/法向夹角、角速度、SAS 目标）、平移区（各轴可用推力实时显示）、旋转区（角速度指示）、主推进方向 6 向单选（**默认 = 推力最大轴向**）、动作组列表（武装状态/总推力）、手动 SAS（对准顺向/逆向/法向/反法向/自定义，复用 Align 执行器）。
- **动作组只影响手动指令**；自动 burn 用主方向锥内全部引擎（不受动作组限制）。

### D8 旋转参与碰撞
- 新增 `GetPartWorldAABB(part, rotation)`：局部半尺寸经 rotation 各轴取绝对值合成世界 AABB，`partMin/partMax` 计算点（CombatManager 命中 / 扫掠检测）统一替换。
- slab / 扫掠膨胀盒 / 分离逻辑不变。

### D9 动量轮不耗电
- 操舵台与动量轮均不接电力闭环；功能解锁即生效。

### D10 输入打断即清空
- **任何手动操舵输入（平移 / 旋转键）→ 清空 `plannedManeuvers` + 取消交会 / 接近引导 + 中止当前 Align/Burn**。
- "手动接管"语义单一、可预测（与现有 `ClearRendezvousGuidance` 玩家接管哲学一致，只是从"规划机动"升级为"任何输入"）。

### D11 撞击不给角速度扰动
- 碰撞只做平移分离（现状）；角速度只由操舵 / 动量轮产生。避免连续碰撞累积乱转，省去偏心 × 冲量的合成逻辑。

### D12 转向机动 = 机动队列一等公民（带时间预留）
- `PlannedManeuver` 加 `kind`：`Burn`（现有）| `Turn`（新增）。
  - **Turn 无 dV、不耗工质、不改轨道**，纯姿态机动，只占用时间。
  - Turn 参数：主推进轴对准的世界方向（预设：顺向 / 逆向 / 法向 / 反法向 + 自定义向量；MVP 先做预设）。
- **时间前滚**：转向时长 = 夹角 / maxAngularRate（线性限速可精确估算）。从当前时刻起每段机动有估算时长（Turn = 转向时长，Burn = 燃烧时长），顺序执行；Turn 完成 → 下一段 Burn 直接点火（已对准）。
- **冲突处理**：插入 / 编辑转向时，**在"机动仍可执行"的前提下**，后续 burn 节点时刻整体后移转向时长；若后移导致机动不可执行（如撞行星保护触发、交会到达时刻锁定）→ 拒绝 / 提示，不动节点。
- **自动对准兜底**：burn 前未排显式转向时，自动生成隐式转向（对准 burnDir），UI 可见可改；**显式转向优先覆盖**兜底。

### D13 矢量 RCS（副网络，微调专用）—— 2026-08-30 新增
- **问题**：交会精度下降——修正 burn 走主引擎需先对准（≤5°/s 转向，最多 ~18s），期间 `HasActiveBurn` 冻结引导闭环（`if (group.HasActiveBurn) continue`），修正方向过期。
- **推进器分类**：`CompProperties_Thruster.isVectoredRcs`（bool）。RCS = **全矢量**（任意方向 = Σ RCS 推力，免对准/免锥），推力小、比冲中等（ve≈4500 液氢、流率 1kg/s）。
- **聚合拆分**（SpaceMapComp）：主引擎进 per-axis（六向判定）；RCS 进独立聚合 `RcsTotalThrust` + 网络级 `RcsThrust/RcsFlow`（不参与主引擎六向）。
- **分发规则**：
  | 场景 | 用哪个 | 对准 |
  |---|---|---|
  | 交会/接近修正（**小修正**：RCS 可在 ~15s 内烧完）| **RCS**（`burnUseRcs=true`）| 无（全矢量，跳过 AlignMainAxis）|
  | 交会/接近修正（**大修正**：RCS 太慢）| **主引擎** | 现逻辑 |
  | 手动操舵平移 | RCS 全矢量 + 主引擎锥内（合并）| 无 |
  | 机动队列大 burn | 主 | 现逻辑 |
  | 无 RCS / RCS 工质尽 | 回退主 | 现逻辑 |
- **修正 burn 网络**：`burnEnabledNetworks = rendezvousUseNetworks`（任务网络），修复沿用上一段机动残留过滤的隐患。
- **教训（2026-08-30）**：最初全部修正走 RCS 反而更差——RCS 推力小（9kN vs 主 45kN），大修正（终端 4446 m/s）用 RCS 要烧 ~20 分钟，期间 `HasActiveBurn` 冻结引导 → 修正全过期 → 死循环。**分发必须按修正量分级：RCS 只做能快速烧完的小修正，大修正走主引擎。**

### D14 交会精度修复（预对准 + 修正打断重烧）—— 2026-08-30
- **问题复盘**：分层后仍差。日志实证三层根因：① 出发 burn 先对准（≤18s）再烧 140s，dV 质心后移 → 初始 miss 2565km；② 修正 burn 期间引导被 `HasActiveBurn` 冻结 → 修正过期；③ 终端消速大（Lambert 只保证到点位置不保证到点速度），被①②放大。
- **D14.1 预对准（前瞻）**：机动可行性通过后、点火前 coasting 段就按机动 dV 方向提前转向主推进轴（`group.pendingAlignDir` + coasting AlignMainAxis）。点火时已对准 → burn 准时居中，初始 miss 恢复。队列空 / 手动接管清 pendingAlignDir。
- **D14.2 修正打断重烧**：`burnIsCorrection` 标记引导修正 burn；引导检查不再被修正 burn 冻结（机动 burn 仍不打断）。烧中重评估：新解 < 死区 → 中断（防过烧）；新解方向与当前偏差 >30° → EndBurn 重烧；否则继续当前烧（避免重复对准）。
- **D14.3 终端消速提前（动态终端窗口）**：日志实证 tof 从 10125s 直接到 45s——巡航 Lambert 只修位置（miss<2km 后 on-course 零烧巡航 ~10080s），到点前 60s 才进终端，4.4km/s 相对速度根本来不及消。改为：终端判定 = 固定 60s **或**「消相对速度所需时间（relVel/a_max）+60s 余量」已逼近剩余时间 → 提前进终端消速，烧中由 D14.2 打断重烧持续精修。
- **D14.4 巡航预对准（终端预姿态）**：出发 burn 完成后船停在出发姿态，终端点火时要从旧姿态转 ~180°（死区叠 4km/s 消速必炸）。改为：引导激活且无 burn 时，每物理步持续对准「目标到达速度 − 本船速度」方向（终端消速方向代理）；修正 burn 点火时由 burn 内部 AlignMainAxis 临时覆盖，烧完自动回归。终端点火时已对准 → 无转向死区。
- **D14.5 终端 = 第二次主推（最终形态，验证通过）**：① 终端 dv = 主引擎全力消速 `vTarget − vShip`（4.4km/s 级主机动）；② **入场门控 = 刹车距离 `relVel²/2aMain`**——过早入场会停短（~1000km），过晚会冲过；③ 速度匹配但距离仍大时补位置收敛（`dr/tof` 轨迹整形）；④ 结论：4.4km/s 相对速度不是"飞掠"，就是第二次主推本身，必须作为主引擎大烧执行。
- **RCS 不参与**：主引擎六向判定、自动对准、动作组只过滤手动指令（自动修正 burn 不受动作组限制）。

## 4. 关键数值与约定

- **矢量锥**：默认 10° 半锥（`cos(10°)≈0.985`），推进器 def 可覆盖（如离子推进可给更宽锥）。
- **maxAngularRate**：默认暂定 ~5°/s，实现时按游戏内手感调（无转动惯量，限速即手感）。
- **转向时长** = 夹角 / maxAngularRate（旋转线性限速，规划可精确估算；Turn 机动的时间预留依据）。
- **动作组语义**：只过滤手动指令；自动 burn 用主方向锥内全部引擎。
- **「需有人操作」设置**：默认关；开启后需指派 pawn 站台操作（工作类型后置）。
- **主推进方向默认值**：未设置时取 `thrustByAxis` 最大轴向；操舵台 UI 可改，改后序列化到 SpaceMapComp。
- **旧存档兼容**：新字段全部带默认值；旧推进器 `thrustAxis` 缺省 = Back（全船引擎视为船尾主推进，行为与现状一致）。

## 5. 施工顺序与验收

### M-a 朝向地基
- `ThrustAxis` 枚举 + 六向坐标系映射；group `angularVelocity` 积分；`rotation` 真实消费（渲染 / 碰撞 AABB 接入）。
- 验收：3D 战斗视图能看到船按 rotation 朝向；旋转后碰撞盒正确（旋转命中验证可复用定向能 T4 场景的 Z 轴 45° 船）。

### M-b 方向感知
- CompThruster axis + MapComp per-axis 聚合 + `GetThrustAlong` + burn 方向过滤 + Align→Burn 状态机 + **转向机动（kind=Turn）与时间前滚**。
- 验收：机动队列执行时先自动转向再点火（日志 `[Align]` 对准→`[Burn]`）；侧向机动被矢量锥拒绝或辅助出力正确；显式排转向 → burn 节点按转向时长后移且顺序执行（Turn 完成才点火）；未排转向 → 隐式自动对准兜底生效。

### M-c 操舵台
