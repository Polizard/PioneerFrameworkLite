## 1. 架构总览（已实现 ✅，2026-08-29 整体式改造后）

> **2026-08-29 系统性修改**：① 上下分体式（Top/Bottom 双锚点）→ **整体式单炮塔**（单 TurretMount，360° 无射界限制）；② 废除上下表面炮口偏移（±yOffset），改为 **出膛点生成**——Map 出膛视觉弹沿瞄准方向飞出本船 AABB 六面（`MapCoordMapper.RayExitAabb`，与 F3 命中共用 slab 几何），物理层射弹在出膛碰撞点生成（Map→3D 转换，F2/F3 对称）。详见 [整体式炮塔改造-20260829](#2026-08-29-整体式炮塔改造)。

```
Pocket Map（= 船）
  ├── CompMapDesignator（定位机：索敌大脑）
  │      ├─ Manual / Auto 索敌（敌对 faction、orbitalEngageRange；360° 无射界过滤）
  │      ├─ 统一冷却齐射（偶数物理步对齐开火）
  │      └─ 驱动绑定炮塔朝向
  └── CompMapTurret × N（整体式炮塔：纯锚点）
         └─ TurretMount（单武器 / 朝向 / 定位机绑定）
                ├─ 出膛点 = 炮口射线 ∩ 本船 AABB 六面（MapCoordMapper.RayExitAabb）
                ├─ CombatManager.FireFromMapBuilding → FireWeapon 链路 → 3D ProjectileInstance（出膛点生成）
                └─ PFProjectile3D 出膛视觉弹（visualOnly：纯视觉，不碰撞己方建筑）
```

**文件**：
- `Base/Buildings/CompMapTurret.cs`：整体式炮塔锚点（单 TurretMount；无反射 Graphic.extraRotation 渲染）
- `Base/Buildings/CompMapDesignator.cs`：定位机（索敌/齐射/360° 射界/出膛点解算/出膛视觉弹/序列化/诊断日志）
- `Base/Core/MapCoordMapper.cs`：格↔船局部↔世界 3D 映射 + `RayExitAabb`（六面出膛点）
- `Combat/PFProjectile3D.cs`：Map 内三维贯穿弹（原版 Projectile 子类；`visualOnly` 纯视觉模式）
- `Combat/CombatManager.cs`：FireFromMapBuilding（复用 FireWeapon）/ SpawnPenetrationMote
- `Defs/Things/Buildings_Turrets.xml`：整体式炮塔 `PF_Building_Turret_Cannon` + 定位机（tickerType=Normal）
- `Defs/Misc/Projectiles_Shell.xml`：PF_Projectile_Shell
- `Defs/Combat/WeaponDefs.xml`：orbitalEngageRange / projectileSpeed

## 2. 坐标与物理规范（✅）

| 规范 | 值 |
|---|---|
| 地图中心 ↔ 船体局部原点 | 地图中心 = entity.Position（Part.localPosition = 0） |
| 1 格 | = 1 米（Part = mapWidth×50m×mapHeight） |
| AABB 面积 | = 地图面积（`AabbHalfSize = BoundsSize × 0.5`，不再 2 倍放大） |
| AABB 高度 | 50m = 内部 10m（船体）+ 上下各 20m 缓冲 |
| 空间站 Part | `isIndestructible = true`（无血条，存亡由 Map 内建筑决定） |
| 射弹物理基准 | physicsTick（double），deltaTime = physicsTick 差值不截断 |
| 开火对齐 | 偶数物理步（`TicksGame & 1`） |
| 降速 | `SetCombatModeImmediate`：射弹生成瞬间进 Combat 档（1/60） |
| 天体位置 | 解析函数接受 double physicsTick（int 化会致 1/60x 下集体闪现） |

**贯穿弹道入口高度规则**（AABB = Map + 上下各 25m，中间 10m 是船体）：
```
|hitY| ≤ 5m（船体厚度内）且入射角小（|vy|/|v| < 10%）
  → y = 0（贴地命中船体墙体，Map 2D 表现）
其他（缓冲空间 / 大角度）
  → y = hitY + sign(vy)×5m，夹到 ≥ 0（Map 无地下）
落点（爆炸）：恒 y = 0
```

## 3. 踩坑记录（关键 bug 与修复）

| # | 症状 | 根因 | 修复 |
|---|---|---|---|
| 1 | 定位机完全不工作 | 建筑 Def 缺 `<tickerType>`（默认 Never，CompTick 不跑） | 4 建筑加 `tickerType=Normal` |
| 2 | 只打一发就哑火 | `WeaponInstance` 冷却无人 tick（炮塔武器未注册 groupWeapons） | `CompMapTurret.CompTick` 每 tick 更新武器状态 |
| 3 | 射弹脱靶 650m | 提前量用**绝对速度**外推目标（`targetPos + targetVel×t`），共轨场景偏出 AABB | 改相对外推 `targetPos + vRel×t` |
| 4 | 轨迹折线（降速前瞬移 19.7km） | 降速生效前 Normal 档 physicsTick 1s/tick 大步进 | `SetCombatModeImmediate`（射弹生成即 Combat）+ 开火对齐偶数步 |
| 5 | 折线（渲染离散点） | 渲染插值 `cachedRenderTick`（physicsTick）与 `lastUpdateRealTick`（TicksGame）单位错位 | 插值统一用 physicsTick 基准 |
| 6 | 尾迹伸缩抖动 | 尾迹连 `proj.prevPosition`（物理点，每 2 tick 跳 167m） | 改固定长度拖尾（沿 velocity 反方向） |
| 7 | 射弹/场景集体闪现 | 天体位置 `GetBodyWorldPosition` 收 int tick，1/60x 下每 60 real tick 跳 1 秒 | 方案 C：天体解析函数 int → double physicsTick |
| 8 | 落点爆炸 NRE 刷屏 | `GenExplosion.DoExplosion` 在太空 Pocket Map 上 terrain/roof 缺失 | 改纯 Mote 视觉（爆闪+烟） |
| 9 | 贯穿弹从地图中心刷出 | 入口点基于 2 倍放大 AABB 出界，兜底 clamp 到 center | AABB 1:1 后入口=地图边缘，clamp 仅防御 |
| 10 | 红字 `Could not find PFMoteShell` | 类已删但游戏侧旧 Def（Motes_Shell.xml）残留 | 删旧 Def；后续清理注意同步游戏侧 |
| 11 | 红字 `Exception ticking PF_Projectile_Shell` | `base.Impact` 先 Destroy，之后 `Position.GetEdifice(Map)` 用已销毁射弹 | 伤害/视觉移到 base.Impact 之前，先缓存 Map/Position |
| 12 | 警告 `Look rotation viewing vector is zero` | 垂直贯穿时 xz 方向零向量 | 覆盖 `ExactRotation` 防御 |
| 13 | **射弹生成后立即误判命中（2026-08-29，全方位场景暴露）** | 开火对齐偶数 tick，与 CombatManager 更新同 tick：`deltaTime=0`（射弹未移动）+ `dtPhysics=0`（目标参考系无回退）→ 相对线段长 0m → slab 检测零方向恒命中（`tEntry=-Inf tExit=Inf`）→ 射弹误判命中遍历到的第一个 group（六发水平弹全打中 G6） | ① `FireWeapon` 补初始化 `prevUpdatePhysicsTick`（默认 0 会让首步 dtPhysics 巨大负数）；② `CheckSegmentGroupHit` 防御：`segmentLength<0.5m` 时 `return false`（无有效相对位移跳过检测，下一物理步恢复后正常判定） |

## 5.1 精确炮击（2026-08-29 新增）

参考 [SOS2but2D CompTargetDesignator.cs](../SOS2but2D/ShipTurret/CompTargetDesignator.cs)（`preciseTargetCell` + `Find.Targeter.BeginTargeting` 选格）。

- **语义**：定位机 Gizmo「设置精确炮击点」→ 锁定目标敌舰（有 Map 者）并跳转其地图 → 点选一格 → 瞄准目标从「船心」偏移到「该格对应的世界点」（格 → 船体局部米 y=0 → `MapCoordMapper.LocalToWorld` 含目标姿态旋转，随船运动/旋转保持）。
- **实现**：`CompMapDesignator` 新增 `preciseStrikeGroupId` + `preciseStrikeCell`（Scribe 落盘）；`GetAimTargetPosition` 统一被 `FireVolley` / `UpdateMountRotations` 使用；目标失效自动清除；`DebugSetPreciseStrike` 调试辅助。
- **日志**：`[精确炮击]`（详细日志）输出瞄准格 / 船心偏移 / 世界瞄准点；`[炮塔出膛]` 出膛方向随偏移点偏转。

## 5. 2026-08-29 整体式炮塔改造（系统性修改记录）

| 项 | 旧（上下分体） | 新（整体式 360°） |
|---|---|---|
| 炮塔结构 | `TurretMountConfig`(Both/Top/Bottom) × `TurretMountSide`(Top/Bottom)，最多 2 锚点 | 单 `TurretMount`（单武器实例），无枚举 |
| 射界 | 半球（上锚点打局部 +Y / 下锚点打局部 -Y），`InHemisphere` 过滤 | 360° 无死角，删除射界过滤 |
| 炮口位置 | 地图格局部 + `yOffset`(±25m) 上下表面偏移 | 地图格局部（y=0）→ 射线出膛点 |
| 物理弹生成点 | 上下表面偏移点（`muzzleLocal.y += ±yOffset`） | 本船 AABB 六面碰撞点（`MapCoordMapper.RayExitAabb`，与 F3 slab 几何对称） |
| Map 侧表现 | 仅炮口长烟 | 出膛视觉弹 `PFProjectile3D`（`visualOnly`：不碰撞己方建筑、无伤害）+ 长烟 |
| Defs | `PF_Building_Turret_Cannon_Top/Bottom/Both` 三变体 | 单一 `PF_Building_Turret_Cannon` |
| 绑定 API | `RegisterTurret(Thing, TurretMountSide)` | `RegisterTurret(Thing)` |

- **关键决策**：出膛点预计算（开火瞬间射线-盒求交）而非事件驱动——与 F3 对称（物理判定先行、Map 视觉随行），零延迟、确定性、不依赖 Map 弹道 tick 时序。
- **详细调试日志（2026-08-29 新增）**：`CombatManager.DebugDetailedCombat`（静态开关）+ `DebugProjectileProbeInterval`（射弹探针，默认 30 tick/条）。日志覆盖全链：`[齐射详情]`（目标状态）→ `[炮塔详情]`（射线输入/出射距离）→ `[炮塔出膛]`（始终输出：出膛面/碰撞点/距离/武器状态）→ `[出膛视觉弹]` → `[射弹生成]`/`[开火详情]`（物理弹生成/出膛偏移/速度继承）→ `[射弹探针]`（飞行状态）→ `[命中详情]`/`[命中Part!]`/`[贯穿生成]`（命中与 Map 映射）。测试场景 `SpawnTurretTest` 自动开启，CompDebugShipSpawner 有「详细战斗日志」Gizmo 开关。
- **单元测试**：`MapCoordMapperTests` 新增 `RayExitAabb` 六面出射用例（轴对齐六面 / 对角线最近面 / 偏移炮口 / 零方向防御），全部通过。
- **验收（游戏内）**：`[炮塔出膛]` 日志验证出膛面与碰撞点；赤道面目标（旧半球射界全过滤）现正常开火命中。
