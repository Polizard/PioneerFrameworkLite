## 2. 控制层（已落地）

### 2.1 点火唯一入口

- `ManeuverPlan`（`Base/Orbital/ManeuverPlan.cs`）：
  - `dv` = 执行方向唯一权威（体心/世界只差平移 ⇒ 同向）；

### 9.9 气动改投影轮廓 + 装配轴对齐机头（2026-10-28 深夜，用户"空气阻力是不是比地球大很多"）

**诊断**：大气参数本来就对（ρ₀=1.2 / H=8000 / 厚 100 km ≈ 地球），但
`GetGroupAeroShape` 把**每件的 CdA 逐轴相加**（4×40 罐 + 12 台引擎 ⇒ 233 m² 迎风面，真值 16 m²），
且 `DefaultDragCoefficient = 1.0`（钝板口径；火箭 0.3–0.5）⇒ 阻力虚高约一个数量级。

**更深一层**：`DesignPartAssembler` 沿 **−Y** 堆零件，而机头/主推轴是 **+Z**
（`ThrustAxis.Back` 默认 ⇒ 推力 +Z），发射又把 +Z 转到当地竖直 ⇒ **组装出的火箭横着飞**，
迎面走 160 m² 的大面。验收 runner 是沿 Z 堆的，所以它能飞、组装器不能。

**改法（三处）**：

1. `AeroShape.DefaultDragCoefficient` 1.0 → **0.35**；
2. `AeroDrag.EffectiveArea` 二次范数 → **盒子解析投影** `Σ|n·轴|·CdA`（对单个盒子精确；
   旧口径斜向低估 42%）。**这是对 D13 旧裁定的反转**：D13 禁的是"**力**逐轴相加"，
   面积投影加权本来就是盒模型正解，前提从"逐件求和"变成"整船包围盒"。
3. `GetGroupAeroShape` → **整船机体包围盒**（`positionShip ± bounds/2` 的并集），一次盒模型；
   O(零件数) 但每件只 6 次 min/max，比原来更省；异形船会被包围盒高估（用户已确认接受）。
4. `DesignPartAssembler`：零件沿 **−Z** 堆、长度落 Z（`boundsY` → ship Z），舱盒厚度也移到 Z；
   `MultipartAcceptanceRunner` 判据 y→z。

**净效果**：迎风 CdA 233 → **5.6 m²**（42×），侧向 160 → 160（不变）。

**判据**：编译 0 error / 209 warning；纯数学气动 **30/30**（+默认 Cd、体对角 √3a²、盒子投影、堆叠不求和）；
游戏模块 **33/33**（+2 条轴向测试）；确定性 `0F93C695…`；交付件 = 部署（仓库 = 游戏目录）。
⚠ 未跑全量闸门；**游戏内未试**。
