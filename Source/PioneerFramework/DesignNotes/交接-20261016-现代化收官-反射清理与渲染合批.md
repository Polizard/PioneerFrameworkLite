- **六条工具纪律**（每条都是当场事故换的）：① 诊断位置必须压在 `new` 关键字上（截距 ≤64）才认节点；② `new[]`（ImplicitArrayCreation）**按规则分叉**（IDE0090 跳过 / IDE0300 是靶子）；③ 带初始化器写 **`new() { … }`**（写 `new { … }` = 匿名类型 ✗）；④ 跨行初始化器**只 Trim 头**（`]` 不许粘进行尾注释）；⑤ 回退定位**必须 CollectionLike**（对象初始化器不许转 `[…]`）；⑥ **裸初始化器** `Type[] X = {…}` 直接换 Initializer 节点。
- **残 34 行逐条留档**：IDE0305 的 18（`ToList/ToArray → [.. x]` 判过不接·与"LINQ 不动"同族）· IDE0301 3（`System.Array.Empty` 全限定）· IDE0090 4（定位未解）· IDE0063 3（会动语义不改）。
