## 4. 现场操作提醒（本线特有的坑，逐条都踩过）

1. **改了 DLL 必须重启游戏**才生效（游戏只在启动时读 DLL）——用户有两次"没生效"都是这个原因。
2. **报告首行写部署状态**；`test-all.ps1` 只写仓库，游戏目录要 `Deploy-LiteToGame.ps1`。
3. **1 tick ≈ 1 物理秒**：凡是"每 N 秒"一律按 dt 累积或直接换算（读数节拍与跑批预算各踩过一次）。
4. **跑批器**：调试页签一键；预算一律写**物理秒**；试验台的油量要够整链（不然"料尽退出"会伪装成功能红）。
5. **两个验收入口别同时跑**（L1 与性能验收）：性能入口一开火 ⇒ 全局 1/60 ⇒ L1 被护栏收场；反向还有一条未修的误杀隐患（§3.3-4）。
6. **清场只能清自己**：跑批器的收工清场**按自己记过的 id**，不许用"按快照清本段新建"（那会误杀别人那段的场景 —— 弹群齐射那次事故）。
7. **校验器**：`validate_config.py` 已有"贴图必须存在 / 自家 Def 元素对得上字段 / 自带 `graphicData` 必须有 `graphicClass`"三条；
   ⚠ 但 `KNOWN_BASE_TEX` 里仍留着**运行时不存在**的 `Things/Building/Ship/ShipSensorCluster`（盲区，见 §3.3-2）。
8. **移植测试偶发红**：`ManeuversTests.Simple.DeltaVToEllipticizeTest` 用**无种子 `Random()`** 撒随机轨道（上游 MJ 原样、逐字移植不许改软）
   ⇒ **红了先单独复跑，再跑闸门；别动测试**。
9. **0 新增警告**是纪律（唯一警告数 = 534 基线，任何 ≠534 视为缺陷并找出来）。
10. **写文件只用 `Write`/`Edit` 工具**，别用带中文的 heredoc（这个 shell 输出编码是 GBK，会把中文写成乱码——交接件真被写乱过一次）。
11. **还原点标签取 `date` 真实读数**（曾凭感觉累加时长，标签快了 14–26 分钟）。
12. **纯测试工程是逐文件源码链接**（不是 ProjectReference）：新增纯核心 `.cs` 要同步 `PioneerFramework.Pure.Tests.csproj` 的 `Compile Include`；
    改文件名要同步 `tools/check-frame-crossing.ps1` 的名单与 `tools/check-frame-names.ps1` 的词表。
